Pengaturan Google Sheets

Website ini menggunakan Google Sheets sebagai database utama untuk SPB, Supir, Asal, dan Tujuan.

Petunjuk Pemasangan Google Sheets:

  1. Buka Google Sheets baru Anda.
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus isi editor dan tempelkan kode Apps Script di bawah ini.
  4. Klik Terapkan (Deploy) > Terapkan Baru (New deployment).
  5. Pilih Jenis: Aplikasi Web (Web App).
  6. Set Akses (Who has access) ke: Siapa Saja (Anyone).
  7. Salin Web App URL dan tempelkan pada kolom di atas.
